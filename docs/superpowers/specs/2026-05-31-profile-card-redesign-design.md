# Редизайн карточки профиля (`/profile карточка`)

Дата: 2026-05-31

## Цель

Полностью переработать карточку профиля (`paintProfileCard`) в стиле референса
(Economy-бот), но с качеством отрисовки уровня Claude design: чёткая иерархия,
типографика, отступы, контраст. Макет — вариант **B (two-zone hero)**.

Затрагивает только `/profile карточка`. Геройские карточки `buildBalanceCard` /
`buildTimelyCard` (используются в `economy.js`) НЕ меняются.

## Макет

Холст 960 × 470. Тёмный диагональный градиент + акцентное радиальное свечение
в левом-верхнем углу (цвет из `accent`/выбранного фона `background.theme`).

### Левая identity-панель (x=28, w=300, h=414)

- Размытый аватар-баннер сверху + затемняющий вертикальный градиент-оверлей.
- Круглый аватар (r≈64) по центру панели, кольцо прогресса уровня, бейдж уровня.
- Имя с акцент-полоской слева + подзаголовок (титул или «Профиль Onix»).
- Внизу две валюты-плитки: **Sakura/Монеты** (`#f5c451` или акцент валюты) и
  **Lotus/Лотусы** (`#a78bfa`), подпись «COIN» + «Обычная»/«Премиум».

### Правая зона (x=352, w=580)

Единая система плиток: fill `rgba(255,255,255,.04)`, hairline-бордер
`rgba(255,255,255,.06)`, радиус 18, внутренние отступы 16, гап между плитками 16.

1. **Полоса ролей/статуса** — 3 компактных однострочных чипа в ряд (~182px, h≈76):
   - чип 1 — любовный статус: процедурный цветок-сакура (акцент) + «Холост»/«В паре».
   - чип 2 — топ-роль сервера: иконка роли (или цветной кружок цветом роли) + имя роли.
   - чип 3 — клан: иконка клана + имя клана (или «Нет клана»).
   Каждый чип: ведущая иконка-бокс (≈40, радиус 12) + текст с обрезкой по ширине.
2. **Сетка статов 2×2** (h≈92): Онлайн, Сообщений, В топе, Достижений
   (иконка + подпись капсом + крупное значение, через существующий `drawTile`).
3. **Ряд достижений** (h≈64): до 3 чипов с последними достижениями; пустые слоты
   рисуются как «Достижение / Отсутствует» (как на референсе).

## Загрузка иконок ролей (окно ~3с, без defer)

Команды не дефёрятся (Components V2), поэтому укладываемся в ~3с. Аватар уже
ограничен `loadRemoteImage(..., 1800)`. Иконку топ-роли грузим **параллельно** с
аватаром (`Promise.all`), используя тот же `loadRemoteImage`. Деградация:

- иконка роли не успела/отсутствует → цветной кружок цветом роли (`role.hexColor`);
- `member` отсутствует (ЛС/не на сервере) → чип роли скрыт;
- canvas недоступен → текущий imgenx-фоллбэк (`getProfileCardUrl`).

## Изменения в коде

- `src/commands/profile.js` — передать уже добытый `member` в `buildProfileCard`.
- `src/services/profileCard.js` — `buildProfileCard({ user, member, profile, clan,
  rank, liveMinutes })`: вычислить топ-роль `{ name, iconUrl, color }` (фильтр
  @everyone, сортировка по `position` убыв.) и любовный статус; грузить аватар +
  иконку роли параллельно; собрать `role`, `love`, `clan`, `achievements` и
  передать в `paintProfileCard`. `buildBalanceCard`/`buildTimelyCard` без изменений.
- `src/services/cardRenderer.js` — переписать `paintProfileCard` под макет B;
  добавить `drawRoleChip(ctx, x, y, w, h, chip, accent)` и
  `drawAchievementsRow(ctx, x, y, w, h, achievements, accent)`; переиспользовать
  `drawTile` / `drawCurrencyTile` / `drawRing` / `drawAvatar` / `themedBackground`.

## spec карточки `paintProfileCard` (новая форма)

```
{
  accent, background:{from,to},
  avatar: Image|null,
  name, subtitle, level, ring:{value,max},
  currencies: [{name, sub, value, color}],          // 2 шт, как сейчас
  chips: [                                            // полоса ролей/статуса (до 3)
    { kind:'love', text, accent },                    // рисуется цветком
    { kind:'role', text, icon:Image|null, color },    // иконка или кружок
    { kind:'clan', text, icon:'clan' }                // flaticon-иконка clan.png
  ],
  tiles: [{icon,label,value}],                        // 4 шт (2x2)
  achievements: [string]                              // 0..N, рисуется до 3 + слоты
}
```

## Проверка

Тестов нет (`npm run check` — только синтаксис). Добавить одноразовый скрипт
`scripts/render-sample-card.js`, рендерящий карточку с моковыми данными в
`tmp/sample-card.png` для визуальной проверки. Прогнать `npm run check`.

## Принципы отрисовки (Claude design)

Типографическая шкала Montserrat; приглушённые подписи `#8b90a3`, яркие значения
`#f4f5fa`; единые 16px-гапы; hairline-бордеры; акцент только на кольце, бейдже,
акцент-полоске имени, значениях валют и иконке любовного статуса.
